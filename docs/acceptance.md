|---|---|---|
| حساب، ورود و خانوار خالی | پیاده‌سازی شده | تنظیم Supabase Auth و آزمون ایمیل تأیید |
| موجودی با سری خرید و تاریخ انقضا | پیاده‌سازی و آزمون دامنه/SQL | اجرای migration روی مقصد |
| کاتالوگ مدیر با نسخه‌بندی | پیاده‌سازی شده | تعیین مدیر و تکمیل سه پیش‌نویس |
| پیشنهاد غذا و محدودیت غذایی | پیاده‌سازی و آزمون | بازبینی ترکیبات کاتالوگ و مقدارهای تخمینی |
| برنامه روزانه و تکرار هفته | پیاده‌سازی و آزمون مرورگر | اتصال حساب واقعی به مقصد |
| نیاز مواد و فهرست خرید | پیاده‌سازی و آزمون | بررسی سناریوی خرید واقعی |
| ثبت خرید و مصرف قابل برگشت | پیاده‌سازی و آزمون دامنه، SQL و مرورگر | اتصال حساب واقعی به مقصد |
| یادآوری داخل برنامه | پیاده‌سازی و آزمون دامنه | تنظیم cron در مقصد |

| ذخیره و بازیابی در پایگاه داده | مسیر واقعی و SQL آزمون شده | اتصال پروژه Supabase |
| حذف حساب و خروجی اطلاعات | پیاده‌سازی شده | آزمون حساب staging |
